# Planungsannahmen zur Entblockung der Umsetzung

Stand 11.11.2026. Elf Detailverträge waren „in Arbeit“, weil das Pflichtenheft eine Festlegung offenlässt. Damit der Bau nicht stillsteht, gilt für jede dieser Lücken eine **Planungsannahme**. Sie ist ein technischer Arbeitsstand, **keine Entscheidung des Auftraggebers** und keine Freigabe (Kap. 07: ein ausbleibender Beschluss ist keine Freigabe). Jede Annahme ist so geschnitten, dass sie sich später durch Konfiguration oder eine Migration korrigieren lässt, ohne Daten zu verlieren. Die Verträge verweisen auf die Nummer. Eine abweichende Entscheidung wird als Beschluss unter `beschluesse/` protokolliert und die betroffenen Tests angepasst.

| PA-01 | `LH-6.1-SYS-003` | Modellregeln der drei Angebotsmodelle fehlen | Drei Modelltypen `AREA_ON_DEMAND` (Flächenbetrieb: Start und Ziel in Zonen, Abholung an Haltepunkt oder Adresse), `LINE_ON_DEMAND` (feste Haltepunktfolge, Fahrt nur bei Anmeldung), `STATION_FEEDER` (ein Bahnhofshaltepunkt als fester Start oder Ziel). ## Wirkung

Die elf Verträge stehen auf „Bereit“ mit Hinweis auf ihre Annahme. Ein WP, das eine Annahme verwendet, nennt das in seinem Bericht. Bei der Abnahme durch den Auftraggeber werden die Annahmen einzeln bestätigt oder ersetzt.
